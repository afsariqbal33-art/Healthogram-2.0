# HEALTHOGRAM — ADMIN CONTROL SYSTEM

## 1. Granular Administrator Roles
- **Compliance Officer**: Review verification submissions (IDs, licenses) and manage badges. (No access to patient medical records).
- **Marketplace Moderator**: Review seller listings, disputes, returns, and catalog compliance.
- **Content Moderator**: Handle user reports, abusive posts, copyright notices, and community guidelines.
- **Operations Admin**: Monitor country payment statuses, delivery partners, and system health.
