# 18 — MULTILINGUAL TRANSLATION & LOCALIZATION

## 1. Supported Languages & Native RTL
* **Primary Languages:** English (`en`) and Arabic (`ar`).
* **Bidirectional Layout Rendering:** Full Right-to-Left (RTL) mirroring across all Jetpack Compose screens for Arabic users.
* **Separation of Concerns:** Application interface language (device/app setting) is kept independent from real-time communication translation settings.

## 2. Real-Time Translation & Transcription
* **Text Translation:** Dynamic message translation for doctor-patient cross-border consultations.
* **Live Captions:** Real-time speech-to-text transcriptions during teleconsultation calls for accessibility.

## 3. Mandatory Medical Disclaimer
Automated translations prominently display the disclaimer:  
*"Notice: Automated translations are provided for communication assistance and do not constitute certified medical interpretation. Clinicians must verify critical medical terms with the patient."*
